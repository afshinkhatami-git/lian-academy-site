# آکادمی لیان — اسکلت پروژه (Eleventy)

این پروژه در همین مرحله **فقط اسکلت** است: سایت اجرا می‌شود، صفحات اصلی
وجود دارند، پوشه‌های محتوا با `admin/config.yml` هماهنگ‌اند و Git آماده
است. طراحی بصری (رنگ، فونت، Layout) عمداً در این مرحله انجام نشده.

## اجرای محلی (روی سیستم خودت)

```bash
npm install
npx @11ty/eleventy --serve
```

بعد سایت روی `http://localhost:8080` بالا می‌آید.

فقط build (بدون سرور محلی):

```bash
npx @11ty/eleventy
```

خروجی در پوشه‌ی `_site/` ساخته می‌شود.

## نکات مهم قبل از ادامه‌ی کار

- `admin/config.yml` سه `TODO` دارد (نام مخزن گیت‌هاب، آدرس OAuth Proxy،
  مسیر media) که باید بعد از تصمیم‌های بعدی پروژه تکمیل شوند.
- فایل‌های `sample-*.md` داخل `src/content/*/` صرفاً نمونه‌ی تستی‌اند؛
  بعداً باید از طریق پنل Decap CMS حذف یا جایگزین شوند.
- `admin/index.html` هنوز به هیچ OAuth Proxy واقعی وصل نیست؛ پنل CMS تا
  آن مرحله عملاً کار نمی‌کند (فقط ساختار فایلش آماده است).
- فرم تماس (`src/contact.njk`) هنوز غیرفعال است (دکمه‌ی ارسال عمداً
  `disabled`) چون اتصال Netlify Function/SMS.ir هنوز انجام نشده.
